# X-TwitterLikedImageScrapper
Requirements
https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/
pip install selenium requests
All other imports (os, time, zipfile, shutil, tempfile, urllib) are built-in Python libraries that don't require installation.

Everything in this program is gonna be deployed into the downloads folder of your OS, don't rely on it too much it usually will crash after scrolling 4-6K images
Select the account name you wanna scrap(your account) and make sure to after running the script and logging into your account you go into the terminal and press enter to continue!
